### 06 守卫 GUARD 复刻说明

- **规则（对齐原版）**：按住 = 男守卫（挡男粉）；松开 = 女守卫（挡女粉）；挡错女粉 → 她起诉骚扰 → 游戏结束；挡错男粉 → 他硬闯过去；分数 = 挡住的人数；守卫绕 VIP 旋转；粉丝越来越快。
- **已做到**：三层叠人 VIP、蓝/红盾环、按住/松开切换、粉丝接近、判定结算、粒子/震屏/顿帧/音效、结算原因。
- **还可以更近**：更丰富的音效、粉丝表情、连击、更多视觉细节。

## 怎么玩

- **最简单**：直接双击各目录里的 `index.html`。
- 或起本地服务（推荐，3D 需要 http 环境）：
  ```
  cd /d F:\GameLab
  python -m http.server 8090
  ```
  访问 `http://127.0.0.1:8090/06-guard/` 等。
